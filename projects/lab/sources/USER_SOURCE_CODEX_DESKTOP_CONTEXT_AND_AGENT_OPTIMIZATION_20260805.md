# Fuente aportada por Jonathan Martínez — optimización de contexto y agentes de Codex Desktop

Document-Role: USER_AUTHORED_SOURCE
Recorded-At: 2026-08-05T12:39:00-04:00
Authority-Effect: SOURCE_FOR_AUTHORIZATION_194

Jonathan Martínez solicitó implementar transversalmente:

- un `AGENTS.md` corto y permanente con reglas estables;
- briefs de ejecución más pequeños que referencien la gobernanza;
- perfiles ligeros `LAB_DISCOVERY`, `LAB_IMPLEMENTATION`, `LAB_VALIDATION` y `LAB_AUDIT`;
- rutas diferenciadas para cambios pequeños, medianos, inciertos y críticos;
- paralelismo exclusivo para trabajo realmente independiente;
- entorno, paths, comandos, incidentes, resultados y stop conditions explícitos;
- recuperación selectiva de errores aplicables;
- medición antes/después de líneas, fuentes, tiempo a primera acción, tiempo total, ciclos de corrección, fallos de validación y consumo.

La optimización no significa «más agentes». Significa menos contexto repetido, mejor asignación de rol, menos exploración innecesaria y paralelismo controlado. El brief canónico completo debe preservarse; la entrega operacional a Codex Desktop debe ser más corta y selectiva.
