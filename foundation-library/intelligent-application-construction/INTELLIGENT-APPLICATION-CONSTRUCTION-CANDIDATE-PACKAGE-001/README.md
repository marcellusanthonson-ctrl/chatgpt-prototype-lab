# Intelligent Application Construction Candidate Package

This package documents selective guidance for turning an approved product problem into a verifiable, operable and safe intelligent application.

It is a candidate, not an integrated capability. It does not authorize AI use, architecture selection, runtime, RAG, embeddings, provider selection, product changes or deployment.

- IAC-01: problem-to-solution framing
- IAC-02: success contract
- IAC-03: simplest viable intelligent approach
- IAC-04: first vertical intelligent slice
- IAC-05: data and evidence readiness
- IAC-06: evaluation and failure analysis
- IAC-07: deployment and safeguards
- IAC-08: monitoring and lifecycle
- IAC-09: generative and agentic extension
