# MOTION-SYSTEM-001

Biblioteca transversal gobernada de motion design del LAB. Clasifica efectos por intención, trigger, fórmula, intensidad, frecuencia industrial, tecnología, rendimiento, riesgo y nivel de personalización.

## Límites

- Un efecto de fundación no es una integración de producto.
- La aprobación del efecto fuente no aprueba automáticamente su extracción genérica.
- `HUMAN_REVIEW_PENDING` es el máximo estado de los dos primeros paquetes.
- Cada adaptación de proyecto requiere un ID derivado, evidencia y autorización separada.

## Flujo

1. Consultar `MOTION_EFFECTS_REGISTRY.json` o `catalog/MOTION_EFFECTS_CATALOG.html`.
2. Seleccionar un efecto por intención y restricciones, no solo por apariencia.
3. Aplicar tokens seguros antes de modificar coreografía.
4. Crear una derivación signature cuando se alteren relaciones bloqueadas.
5. Validar reduced motion, rendimiento, geometría y continuidad perceptual.
