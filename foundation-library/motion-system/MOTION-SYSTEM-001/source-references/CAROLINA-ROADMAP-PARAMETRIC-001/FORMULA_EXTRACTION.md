# Extracción de fórmula

El efecto define un sistema local del timeline. Mide centros de nodos, deriva el rail entre el primer punto y una cola basada en la última tarjeta, vincula el relleno a una línea del viewport y calcula progreso por etapa. Los coeficientes visuales pueden variar; las relaciones de normalización, clamps y recálculo permanecen bloqueadas.
