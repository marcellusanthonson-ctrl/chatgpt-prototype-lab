# Límites de personalización

- **Locked invariants:** semántica, límites, identidad DOM requerida, estado final, reduced motion y relaciones matemáticas estructurales.
- **Safe tokens:** duración, delay, easing, distancia, opacidad, escala, stagger y threshold dentro de rangos validados.
- **Choreography:** secuencia, prioridad y paralelismo; exige revalidación.
- **Visual adaptation:** tipografía, color, materialidad, máscaras y profundidad; depende del proyecto.
- **Signature derivation:** altera carácter o relaciones; requiere nuevo ID, parent, demo, evidencia y aprobación.
